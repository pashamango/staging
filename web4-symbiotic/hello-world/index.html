WEB4 Symbiotic Interface — Hello World

Quantum 1, draft, staging only. This is not production, not estate root, not a biometric system.

Ontology, in one formula:

Identity = OnDeviceBiometricUnlock(Key) + Sign(Challenge) + NodePresence(Tailscale/WiFi)

WiFi alone is NOT biometrics. WiFi is presence. Biometrics never leave the device (Secure Enclave / TPM / Titan). Only a signature travels.

Principal: Pavel Cherkashin, participant in the QSA project namespace (Quantum States of America, as defined by the WEB4 project — not a legally recognised citizenship).

Test platform: Wolfram (Mac). Hub: Darwin. No changes to pentagi, Darwin hub, or production in this quantum.

1. Identify (WebAuthn, on-device only)

Clicking Identify asks your browser for a platform authenticator (Touch ID / PIN / security key, whatever this machine has). No fingerprint, face or voice data is sent anywhere — the browser signs a challenge locally and shows the result here.

Not identified yet.

2. Chat bridge, hello-world form

A signed message file, readable by curl from any context, is the bridge in this quantum:

curl https://pashamango.github.io/staging/web4-symbiotic/hello-world/hello.json (after staging tap — not live yet)

Or locally: curl hello.json next to this page. The file contains a TEST signature only. Its private TEST key was deleted after signing. It is NOT estate root.

3. Accessibility, honestly

No accessibility grant is requested or used by this page. A helper app on Wolfram would need an explicit, revocable grant from Pavel in macOS Settings, for a named app and a named purpose, with all actions logged. That grant is a later quantum, and it cannot be given via SSH.
