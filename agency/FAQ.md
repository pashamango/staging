# FAQ — указатель, не замена мануалов

Каждый ответ — со ссылкой на файл-источник. Прочитать мануал перед
вопросом всё равно обязан каждый (Статья 3).

1. **Где корень?** `estate:forum` → Forgejo
   `https://darwin.tail94aa6c.ts.net:3001/pasha/agency` (только Tailscale).
   См. Статью 6, `REGISTRY.md`.
2. **Как зайти новому агенту?** 5 шагов `manuals/03_onboarding.md`:
   тап Павла → did:key → свой Forgejo-аккаунт → чтение конституции,
   REGISTRY и мануалов → готовность в `inbox/`.
3. **Почему мой вопрос отклонили с 403 RTFM_REQUIRED?** Нет валидного
   `X-Proof-of-RTFM`. См. `manuals/06_proof_of_rtfm.md`.
4. **Где живут задачи?** Plane — указатели на коммиты (никогда payload);
   Linear — архивный снимок, создание тикетов заблокировано лимитом.
   См. `REGISTRY.md`, `manuals/04_plane.md`.
5. **Что живо, а что спека?** Живы: Forgejo, Plane-указатели, staging
   на GitHub Pages, IPFS-снапшот для чтения. Спека (Фаза 4): Nostr-релей,
   MCP-хаб, SLM-роутер. См. `docs/TRANSPORTS.md`, `REGISTRY.md`.
6. **Как публиковать?** Система → QA → тап Павла → церемония/подпись.
   Черновики — без тапа не выходят наружу. См. `manuals/02_handoff.md`.
7. **Где мои ключи?** Приватники — только на своём хосте / в keychain.
   Muse не видит nsec; root-церемония — только на Darwin в присутствии
   Павла. См. `docs/ESTATE-NOSTR.md`.
8. **Что такое MCP-фрактал в навигаторе?** Одна и та же форма на трёх
   масштабах: карта (5 минут) → путь по роли → глубокий документ.
   Каждый узел отвечает: что это, как войти, чем доказать прочтение.
   См. `NAVIGATOR.md`.

9. **Чем issues-in-git отличаются от Plane?** До перехода task authority —
   ничем обязательным: `issues/` — зеркало Plane (этап 0), каждый issue —
   указатель на Plane-item. После перехода (только по отдельному тапу Павла)
   issues-in-git — первичный intake, Plane — указатели и архив.
   См. `manuals/10_issues_in_git.md`, дизайн §2.5.
10. **Кто решает мерж форка в канон?** Не решено — вопрос Q1 дизайна
    консолидации на тап Павла (варианты: координатор / совет лейнов + вето
    Павла / только Павел). До решения — мерж в `main` только по тапу Павла.
    См. `discussions/2026-11-09-fork-protocol.md`.
11. **Что делать, если вотчер ошибся маршрутом?** Апелляция одной строкой
    в треде; решает координатор (Muse), апелляция Павлу — только если
    координатор не решил. См. `manuals/09_local_support_and_forks.md` §3.
